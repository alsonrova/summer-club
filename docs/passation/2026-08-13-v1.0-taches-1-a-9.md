## Pièges de l'environnement, à ne pas redécouvrir

- **`next dev` ne sert rien sur cette machine** : il démarre, n'émet aucun log et ne répond jamais. Playwright vise donc `npm run start` ; **un `npm run build` doit précéder `playwright test`**.
- **`npm install` prend 10 à 20 minutes** sur ce disque. Windows Defender analysant `node_modules` est le suspect principal — une exclusion sur `D:\Projet` réglerait probablement le problème.
- **Ne jamais lancer deux `npm install` en parallèle** : ça a corrompu `node_modules` deux fois, dont une qui a rendu `next` inutilisable.
- **Prisma est épinglé en 6.19.3.** La v7 supprime `url = env("DATABASE_URL")` dans le schéma.
- `prisma migrate dev` échoue sans terminal interactif dès qu'il doit afficher un avertissement. Contournement : `prisma migrate diff` puis `prisma migrate deploy`.
- Node exécute le TypeScript nativement (`node --experimental-strip-types`) : `tsx` est inutile.
- La configuration du serveur de prévisualisation vit dans `D:\Projet\.claude\launch.json` (entrée `summerclub`), pas dans le sous-projet.
